# Customer Segmentation Analysis

## 📊 Project Overview

This project analyzes customer purchasing behavior and identifies different customer segments using data analytics and machine learning techniques.

The objective is to transform raw customer data into actionable business insights that can support marketing, customer retention, and business decision-making.

## 🎯 Business Objectives

* Understand customer purchasing behavior
* Identify high-value customers
* Analyze customer recency, frequency, and monetary value
* Segment customers based on their behavior
* Identify customers who may require retention strategies
* Create an interactive business dashboard
* Translate analytical results into business insights

## 🛠️ Technologies Used

## 🔎 Analysis Process

The project follows a complete data analytics workflow:

1. Data preparation
2. Data cleaning
3. Exploratory Data Analysis (EDA)
4. Customer behavior analysis
5. RFM analysis
6. Customer segmentation
7. K-Means clustering
8. SQL analysis
9. Data visualization
10. Business insights and recommendations

## 📈 Key Performance Indicators

The analysis focuses on several business KPIs:

* Total Customers
* Total Revenue
* Average Order Value
* Purchase Frequency
* Customer Recency
* Customer Lifetime Value
* Revenue by Customer Segment
* Customer Distribution by Segment

## 🧠 Customer Segmentation

K-Means clustering is used to group customers according to similarities in their purchasing behavior.

The segmentation considers variables such as:

* Recency
* Frequency
* Monetary Value
* Total Spending
* Number of Orders
* Average Order Value

## 📊 Dashboard

The Power BI dashboard provides an interactive overview of:

* Customer KPIs
* Revenue performance
* Customer segments
* RFM distribution
* Spending behavior
* Customer purchasing patterns

## 💼 Business Questions

The project addresses questions such as:

* Which customers generate the highest revenue?
* Which customer segments have the highest purchasing frequency?
* Which customers show signs of reduced activity?
* How is revenue distributed across customer segments?
* Which customer groups could be targeted by different marketing strategies?
